# Руководство пользователя

## Регистрация и авторизация

При первом запуске пользователь создаёт учётную запись. Для последующих запусков используется авторизация. Данные каждого пользователя логически отделены в Firestore.

## Заполнение профиля

В стартовой анкете предусмотрены следующие сведения:

- имя;
- дата рождения;
- категория здоровья;
- субъективная оценка уровня метеочувствительности.

В проекте рассматриваются группы пользователей: гипотоники, гипертоники, пользователи с мигренями, пользователи с заболеваниями суставов и общая группа. Профиль используется для персонализации прогноза и рекомендаций.

## Главный экран и прогноз

Главный экран предназначен для просмотра погодной обстановки и прогноза риска ухудшения самочувствия. Для оценки рассматриваются:

- атмосферное давление и его изменения;
- температура и резкие перепады температуры;
- влажность;
- ветер и осадки;
- облачность и освещённость;
- жара и холод;
- пыльца и грозовые условия;
- геомагнитная активность, выраженная Kp-индексом.

Прогноз содержит уровень риска, причины оценки, вероятные симптомы и профилактические рекомендации.

### Уровни риска

| Уровень | Цветовая индикация | Интерпретация |
|---|---|---|
| Низкий | Зелёный | Значимый риск по принятой логике не выявлен |
| Средний | Жёлтый | Следует обратить внимание на факторы риска и самочувствие |
| Высокий | Красный | Рекомендуется проявить повышенное внимание и следовать доступным профилактическим советам |

Индекс благополучия отображается в диапазоне 0–100%. Конкретная формула преобразования факторов в итоговое значение в исходном описании не раскрыта.

## Создание записи метео-дневника

Запись помогает сопоставлять погодные условия с индивидуальным самочувствием.

В дневнике предусмотрены следующие данные:

| Поле | Что фиксируется |
|---|---|
| Дата и время | Момент создания записи |
| Самочувствие | Субъективная оценка состояния |
| Симптомы | Наблюдаемые пользователем симптомы |
| Энергия | Уровень энергии |
| Стресс | Субъективный уровень стресса |
| Сон | Качество сна |
| Пульс | Значение пульса, если пользователь его фиксирует |
| Активность | Физическая активность |
| Вода и кофеин | Потребление воды и кофеина |
| Медикаменты | Сведения о приёме препаратов |

Порядок действий:

1. Откройте раздел дневника.
2. Создайте новую запись.
3. Заполните доступные показатели.
4. Выберите симптомы, если они присутствуют.
5. Сохраните запись.
6. Проверьте, что запись появилась в истории.

## Рекомендации

Рекомендации формируются с учётом погодных причин, вероятных симптомов и категории пользователя. В базе советов предусмотрены темы:

- достаточное потребление воды и отдых;
- снижение физической активности и стресса;
- контроль давления;
- защита от перегрева, холода и ветра;
- ограничение кофеина;
- проветривание помещения;
- снижение контакта с аллергенами;
- соблюдение режима сна;
- приём только назначенных врачом препаратов;
- дыхательные практики.

Если риск достигает значимого уровня, базово добавляются советы пить воду и больше отдыхать. При высоком риске дополнительно предлагается снизить физическую активность и избегать стресса. Рекомендации не заменяют назначения врача.

## Статистика и уведомления

Раздел статистики предназначен для просмотра истории записей и графиков. В настройках предусмотрено управление push-уведомлениями, триггерами, допустимым временем получения сообщений и порогом риска.

Для технического описания полей см. [Справочник](reference.md).
