# Справочная информация

## Погодные и геомагнитные факторы

| Фактор | Значение для анализа |
|---|---|
| Атмосферное давление | Учитывается значение и его изменение |
| Температура | Учитываются температура и резкие перепады |
| Влажность | Дополнительный метеорологический фактор |
| Ветер | Учитываются скорость/условия ветра |
| Осадки | Учитывается наличие осадков |
| Облачность и освещённость | Контекстные погодные признаки |
| Пыльца | Фактор возможного аллергического воздействия |
| Грозы | Учитываются грозовые условия |
| Kp-индекс | Показатель геомагнитной активности |

## Категории пользователей

- гипотоники;
- гипертоники;
- пользователи с мигренями;
- пользователи с заболеваниями суставов;
- общая группа.

## Симптомы

В проекте предусмотрен enum `SymptomType`. Среди категорий указаны головная боль, мигрень, головокружение, слабость, утомляемость, суставная боль, боль в спине, учащённое сердцебиение, скачок давления, пониженное давление, раздражительность, тревожность, бессонница, сонливость, тошнота и дискомфорт дыхания.

Для причин риска предусмотрен enum `RiskReason`. Полный перечень значений этого enum в доступном описании не приведён.

## Логика рекомендаций

В сервисе `PersonalModelService` определяется неблагоприятное состояние пользователя. При оценке учитываются низкая оценка самочувствия, тяжёлые или несколько умеренных симптомов, снижение энергии, повышенный стресс, ухудшение сна и выход пульса за нормальный диапазон.

К тяжёлым симптомам в описании отнесены мигрень, головокружение, сердцебиение, скачок давления, пониженное давление, дискомфорт дыхания и тошнота. К умеренным — головная боль, слабость, утомляемость, суставная и спинная боль, раздражительность, тревожность, бессонница и сонливость.

Пример фрагмента логики ниже иллюстрирует только правило, описанное в отчёте. Это не дословный исходный код проекта:

```python
def base_recommendations(risk_level: str) -> list[str]:
    recommendations = []

    if risk_level in {"medium", "high"}:
        recommendations.extend([
            "Пейте достаточно воды",
            "Уделите время отдыху",
        ])

    if risk_level == "high":
        recommendations.extend([
            "Снизьте физическую активность",
            "Избегайте дополнительного стресса",
        ])

    return recommendations
```

## Индекс благополучия

Индекс отображается в диапазоне 0–100%. Визуальная индикация уровня риска использует зелёный, жёлтый и красный цвета для низкого, среднего и высокого уровней соответственно. Точная математическая формула индекса в исходном описании отсутствует.
