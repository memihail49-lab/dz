# Установка и настройка

## Состав программного продукта

WeatherHealth проектируется как мобильное приложение с серверной частью и облачным хранилищем.

| Компонент | Технологии, указанные в проекте | Назначение |
|---|---|---|
| Мобильное приложение | Kotlin, Jetpack Compose | Пользовательский интерфейс |
| Архитектура клиента | MVVM, Clean Architecture | Разделение UI, бизнес-логики и данных |
| Сетевое взаимодействие | Ktor Client, Kotlinx Serialization, Coroutines, Flow | HTTP-запросы и обработка данных |
| Внедрение зависимостей | Koin | Управление зависимостями |
| Авторизация и облачные данные | Firebase Auth, Firestore | Учётные записи и хранение данных |
| Уведомления | Firebase Cloud Messaging | Push-уведомления |
| Backend | Python, FastAPI, uvicorn | API и серверная логика |
| Аналитика | pandas, numpy, scikit-learn, Logistic Regression, joblib | Подготовка признаков и персональная модель |
| Фоновые задачи | APScheduler | Периодическое обновление и уведомления |
| Развёртывание | Docker, Docker Compose | Контейнеризация серверной части |

## Системные требования

В исходном описании проекта не указаны минимальные версии Android, Android Studio, Python и библиотек, а также минимальные объёмы памяти и дискового пространства. Поэтому ниже приведён перечень требований к окружению без выдуманных числовых ограничений.

| Область | Требование |
|---|---|
| Мобильная разработка | Среда Android Studio с поддержкой Kotlin и Jetpack Compose |
| Backend | Среда выполнения Python |
| Контейнеризация | Docker и Docker Compose — для предусмотренного контейнерного запуска |
| Хранилище | Настроенный проект Firebase с Firestore |
| Уведомления | Настроенная интеграция Firebase Cloud Messaging |
| Сеть | Доступ к интернету для внешних погодных и геомагнитных источников |

## Подготовка backend

1. Получите исходный код серверной части проекта.
2. Создайте виртуальное окружение Python.
3. Установите зависимости, перечисленные в проекте.
4. Настройте доступ к Firebase Admin SDK.
5. Укажите конфигурацию внешних сервисов и серверного окружения.
6. Запустите backend выбранным способом — непосредственно через uvicorn либо через Docker Compose, если соответствующие файлы присутствуют в репозитории.

Пример создания виртуального окружения:

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Пример запуска FastAPI-приложения (имя Python-модуля и объекта приложения необходимо сверить с фактическим исходным кодом):

```bash
uvicorn main:app --reload
```

## Подготовка мобильного приложения

1. Откройте Android-проект в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Проверьте конфигурацию Firebase для приложения.
4. Убедитесь, что адрес backend задан в конфигурации клиента.
5. Соберите и запустите приложение на эмуляторе или совместимом устройстве.

> **Примечание.** Название модуля, точные команды сборки, URL backend и значения конфигурации не приведены в исходном отчёте. Их необходимо взять из фактических файлов проекта, а не копировать из примеров без проверки.
